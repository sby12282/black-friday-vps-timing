## 常见问题

**黑五当天一定最便宜吗？**

不一定。HostDZire 在 LET 原帖里直接写了"正日不保证再降"，PureVoltage 的早鸟价和黑五场是两套货。真正在 27 号集中放的是大商家的限量闪购，抢不抢得到是另一回事。看到合适的早鸟价，不必为了等一个不确定的折扣放着不买。

**早鸟和正日怎么权衡？**

看你要的东西是否限量。限量款（Nuyek 20 台独服、RakSmart $1.99 秒杀、VM6 每人 1 台）早买早有，晚一天就没了。非限量的常规套餐（LightLayer 这类）价格本来就是公开的，早买晚买差别不大，早买早用。

**$1.99/月 的机器能干什么？**

2C2G / 50G HDD / 5G 口 / 10T，跑测试环境、轻量代理、小流量站点可以。HDD 的 IO 撑不住数据库，共享带宽在高峰期会掉速，别放生产业务。

**半年付的套餐怎么算年成本？**

把半年价乘 2。NoslaCloud 东京 1C1G 是 ¥699/半年，一年 ¥1398；1C2G 是 ¥1059/半年，一年 ¥2118。拿半年价直接当年价对比会误判。

**德国广播 IP 有什么影响？**

IP 的 GeoIP 归属显示德国，实际机器在美国或日本。影响三件事：流媒体解锁判定、部分按地区风控的网站、以及你自己做地域统计时的准确性。做外贸站、需要本地 IP 属性的业务要提前想清楚。
